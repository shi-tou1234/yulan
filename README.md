# Markdown 预览器

基于浏览器的实时 Markdown 编辑器，左侧输入，右侧即时渲染。支持标准 GFM Markdown 语法，以及丰富的自定义扩展语法，无需构建工具和本地服务，直接用浏览器打开即可运行。

## 功能特性

### 基础编辑

- **双栏编辑**：左侧源码编辑，右侧实时预览
- **双向选区联动**：编辑区与预览区选区同步高亮
- **自动保存**：内容自动写入 `localStorage`，刷新不丢失
- **Markdown 导出**：一键下载 `.md` 文件
- **字数统计**：实时显示字符数
- **Tab 键支持**：编辑器内 Tab 缩进 / Shift+Tab 反缩进

### 标准 Markdown (GFM)

- 标题 (H1-H6)、段落、换行
- 文本强调：**粗体**、*斜体*、***粗斜体***、~~删除线~~
- 引用块、嵌套引用
- 有序列表、无序列表、任务列表
- 链接、图片、表格
- 行内代码、代码块（带语法高亮）
- 脚注 (`[^1]`)，文末自动生成编号列表
- 水平线

### 数学公式

- 行内公式：`$...$`
- 块级公式：`$$...$$`
- 公式推导浮层：`:::derivation` 容器，hover/点击公式展开推导过程

### 自定义扩展语法

在标准 Markdown 之上，支持以下扩展语法（样式可嵌套，如 `!!==模糊彩虹==!!`）：

| 语法 | 效果 | 说明 |
| --- | --- | --- |
| `++文本++` | 下划线 | 彩色下划线强调 |
| `!!文本!!` | 模糊/剧透 | 模糊遮蔽，悬停或点击后清晰显示 |
| `==文本==` | 彩虹文字 | 动态彩虹渐变动画文字 |
| `{汉字}(hàn\|zì)` | 拼音注音 | Ruby 注音，支持逐字 `\|` 分隔 |
| `[^1]` | 脚注 | 文末自动生成编号列表并支持跳回 |
| `:::quote` | 引用卡片 | 装饰性引用块，`<right>—— 出处</right>` 右对齐落款 |
| `:::note` / `:::tip` / `:::important` / `:::warning` / `:::caution` | 提示框 | 带图标和颜色的警示框，支持 `{name="自定义标题"}` |
| `:::derivation` | 推导容器 | 隐藏块，hover/点击前一个公式时浮层展示 |
| `::github{repo="用户名/仓库名"}` | GitHub 仓库卡片 | 自动拉取仓库信息（描述、Star、Fork、语言） |
| `::music{id="歌曲ID"}` | 网易云音乐卡片 | 自动拉取歌曲信息（封面、歌名、艺术家） |
| `![alt](url "title")` | 图片说明 | 自动包裹 figure/ffigcaption |
| ` ```language ` 代码块 | 代码复制按钮 | 悬停显示复制按钮，点击一键复制 |

### 主题与界面

- **主题切换**：亮色（暖纸色）/ 暗色（深蓝紫）模式，偏好自动记忆
- **工具栏**：20+ 快捷插入按钮，支持 tooltip 提示
- **响应式设计**：适配移动端，双栏自动切换为上下布局
- **打印样式**：隐藏工具栏和编辑器，只打印预览内容

## 使用方式

直接用浏览器打开 `index.html` 即可运行，无需构建工具和本地服务。

## 技术栈

- **marked**：Markdown 解析（GFM + 脚注）
- **KaTeX**：数学公式渲染
- **Highlight.js**：代码语法高亮
- **DOMPurify**：HTML 净化（XSS 防护）

## 项目结构

```text
D:\项目\Markdown预览器
├── index.html          # 应用骨架，引入样式、外部 CDN 依赖和主脚本
├── css/
│   └── style.css       # 双栏布局、工具栏、预览区、主题变量、自定义效果样式
├── js/
│   └── app.js          # 主逻辑：渲染、事件、卡片、工具栏
└── README.md           # 项目说明
```

## 自定义语法示例

输入以下 Markdown 即可看到对应效果：

````markdown
## 下划线
++这是一段带下划线的文字++

## 模糊/剧透
!!这是隐藏内容，点击或悬停查看!!

## 彩虹文字
==这段文字会呈现彩虹渐变动画效果==

## 拼音注音
{学习}(xué xí) {中文}(zhōng wén)

## 脚注
这是一段包含脚注的文字[^1]。

[^1]: 这是脚注的内容。

## 引用卡片
:::quote
知识就是力量。
<right>—— 弗朗西斯·培根</right>
:::

## 提示框
:::note{name="笔记"}
这是一个带自定义标题的笔记提示框。
:::

:::warning
请注意：这是一个警告提示。
:::

## GitHub 卡片
::github{repo="vercel/next.js"}

## 音乐卡片
::music{id="1404885291"}

## 公式推导
$$
E = mc^2
$$

:::derivation
质能等价公式由爱因斯坦于 1905 年提出。
$E$ 表示能量，$m$ 表示质量，$c$ 表示光速。
:::

## 图片说明
![风景](https://picsum.photos/400/250 "美丽的自然风光")
````

## 注意事项

- 首次加载依赖网络访问 CDN，若离线使用需提前缓存相关资源
- 本地存储内容仅保存在当前浏览器中，不会自动同步到其他设备
- GitHub 卡片和音乐卡片依赖外部 API，需要网络连接才能加载数据
- 脚注、GitHub 卡片、音乐卡片等功能基于 GFM 和自定义预处理实现
